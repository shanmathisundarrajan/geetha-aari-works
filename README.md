# Geetha Aari Works

Website for **Geetha Aari Works** — a home-based aari blouse designing and stitching business in Cheyyar, Thiruvannamalai District, Tamil Nadu.

🔗 **Live site:** https://geetha-aari-works.vercel.app/

## About

Budget-friendly aari work blouse designing and stitching, made to customer measurements. The site showcases reference designs and lets customers place an order directly through WhatsApp or Instagram.

## Features

- Reference gallery of aari work blouse designs
- Order form (name, phone, size, address, design notes)
- Order via **WhatsApp** — opens a pre-filled chat
- Order via **Instagram** — copies the order details and opens Instagram DMs
- Fully responsive, single-file website (no backend required)

## Tech

Plain HTML, CSS and JavaScript — a single `index.html` file, deployed on [Vercel](https://vercel.com).

## Updating the site

1. Edit `index.html` locally.
2. Commit and push the change:
   ```
   git add .
   git commit -m "update"
   git push
   ```
3. Vercel automatically redeploys the live site within a minute.
